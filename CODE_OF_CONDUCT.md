# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful and constructive; assume good faith; critique code and numbers, not people. Harassment, personal attacks, and publishing others' private information — including anyone's financial data — are not tolerated anywhere in this project's spaces (issues, pull requests, discussions).

This is a tax tool. Reports and examples must be redacted or synthetic; never post real account numbers, statements, or positions, yours or anyone else's.

Report unacceptable behaviour to the maintainer at the address in [SECURITY.md](SECURITY.md). Reports are handled privately; the maintainer may warn, temporarily restrict, or ban participants, proportionate to the behaviour.
