# taxjson brand files

- `logo.svg` — the mark: JSON braces around a check mark (computed, verified). Also the website's favicon.
- `logo-512.png` — the mark as a 512 px PNG (avatars, app icons).
- `social-preview.png` — 1200 × 630 link-preview image (GitHub social preview, taxjson.com `og:image`).

Colours: green `#0f6e56`, mint `#8fd3bd`, paper `#f6f7f4`, ink `#141a17`.
